# PULSO

PULSO es la app Vento OS para salon, ordenes/POS operativo y scanner de flujos cliente/loyalty.

## Rutas principales

- `/salon`
- `/orders`
- `/scanner`

## Desarrollo

```bash
npm install
npm run dev
```
